# 风影靴

## 基本信息

- 类型：身法增益法器
- 形态：乌黑色皮靴，由某种妖兽皮制成
- 特性：柔软有韧性，穿戴后大幅提升身法速度
- 原主：[封岳](../01-人物/封岳.md)

## 身份/定义

封岳的乌靴法器，以某种妖兽皮制成。穿戴后身法速度远超御风决，配合罗烟步可达到近乎"隐形"的移动速度。封岳诡异身法的秘密来源。

## 首次登场

- [第三卷第一百九十章 乌靴](../08-章节/第三卷第一百九十章%20乌靴.md)

## 当前已知关系

- 与 [封岳](../01-人物/封岳.md)：原主人，因其获得诡异身法
- 与 [韩立](../01-人物/韩立.md)：封岳被杀后被韩立获得
- 与 [罗烟步](../03-功法/罗烟步.md)：配合使用可产生幻影效果
- 与 [御风决](../03-功法/御风决.md)：速度远超御风决

## 关键事件

1. 天雷子击杀封岳后，乌靴是唯一幸存之物
2. 韩立发现其不被火弹术毁坏，察觉为法器
3. 韩立试穿后发现速度大幅提升，可配合罗烟步产生幻影
4. 韩立对此靴极为重视，称即使以符宝换取也不会考虑
