# 暖阳宝玉

## 基本信息

- 类型：宝玉（宝物）
- 位置：在墨府中

## 身份/定义

墨大夫遗书中提到的宝物，可以解韩立体内的阴寒之毒。韩立通过遗书得知解尸虫丸解药中含阴毒，需要暖阳宝玉才能彻底解毒。当前严氏已将宝玉交给心腹之人，如有风吹草动会立即毁掉宝玉，作为谈判筹码。严氏开出消灭五色门和独霸山庄的交换条件。

## 当前已知关系

- 与 [韩立](../01-人物/韩立.md)：韩立急需得到此物来解毒，严氏以消灭五色门和独霸山庄为交换条件
- 与 [严氏](../01-人物/严氏.md)：已将宝玉交给心腹之人，有销毁后手
- 与 [墨府](../05-场景/墨府.md)：存放于墨府
- 与 [墨玉珠](../01-人物/墨玉珠.md)：可能作为其陪嫁落到吴剑鸣手上
- 与 [五色门](../02-组织/五色门.md)：严氏要求韩立消灭的敌对帮派之一，作为交换条件
- 与 [独霸山庄](../02-组织/独霸山庄.md)：严氏要求韩立消灭的敌对帮派之二，作为交换条件

## 关键事件

- 韩立得知必须得到暖阳宝玉才能解体内阴毒
- 韩立估计阴毒最多两个月就会爆发，急需拿到宝玉
- 严氏将暖阳宝玉交给心腹之人作为销毁后手，威胁同归于尽
- 严氏开出消灭五色门和独霸山庄换暖阳宝玉的条件
- 韩立拒绝一人对抗大帮会的提议，提出两选一
