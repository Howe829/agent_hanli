# 青蛟旗

## 基本信息

- 类型：法器（风属性攻击型）
- 品阶：顶级法器
- 形态：长约丈许的青色大旗，旗面上绣着张牙舞爪的凶恶青蛟
- 原主：[陆师兄](../01-人物/陆师兄.md)
- 属性：风系法术增幅法器

## 身份/定义

顶级攻击型法器，在顶级法器中大大有名。能毫不费力地瞬发出风刃术等简单法术，因吸纳了灵气，所有从旗上发出的风属性攻击都经过增幅。看似初级下阶法术的风刃，实际威力足与中阶法术媲美。

可化为十几丈长的青色巨蛟攻击敌人，栩栩如生。

## 当前已知关系

- 与 [陆师兄](../01-人物/陆师兄.md)：陆师兄为了配合自身灵根属性不知花费多少心血代价才弄到手，是其威力最大的法器
- 与 [韩立](../01-人物/韩立.md)：在恶斗中与韩立的符宝巨剑正面交锋，旗鼓相当

## 关键事件

1. 陆师兄在恶斗中亮出此旗，本想发动杀招但被韩立抢先攻击而被迫防御
2. 聚集灵气后发出十几道半月形青色风刃，几乎击碎韩立的[精钢环](./精钢环.md)
3. 持续发出风刃流，击碎精钢环后被[玄铁飞天盾](./玄铁飞天盾.md)挡住
4. 陆师兄全力催动下化为十几丈长青色巨蛟，与韩立符宝化的巨剑纠缠对峙
5. 最终因陆师兄法力耗尽被韩立的符宝巨剑消磨至丈许长
