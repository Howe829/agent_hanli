# 墨大夫

## 基本信息

- 年龄：外表六十余岁，实际年仅三十七岁
- 身份：七玄门大夫、供奉堂供奉
- 外貌：高高瘦瘦，面皮焦黄，长到披肩的白发
- 特征：不断咳嗽，看似体弱

## 身份/定义

七玄门内地位极高的医者。外表看似随时可能倒下，但在门内地位非同一般——张均认为其比堂主甚至副门主更值得尊敬。在神手谷内拥有独立的药田和居所。

## 当前已知关系

- 与 [韩立](./韩立.md)：韩立为其亲传弟子，韩立的修炼成果引发其异常狂热反应。韩立具有罕见的"灵根"体质，是墨大夫找过的数百名童子中唯一能修炼长春功的人
- 与 [张铁](./张铁.md)：传授象甲功，张铁根骨适合此功
- 与 [七玄门](../02-组织/七玄门.md)：门内大夫，供奉堂供奉，地位极高
- 与 [王陆](./王陆.md)：曾救王陆门主性命
- 与 [无名口诀](../03-功法/无名口诀.md)：传授者，对此口诀极为重视
- 与 [象甲功](../03-功法/象甲功.md)：将此功传授给张铁，明确告知利弊
- 与 [供奉堂](../02-组织/供奉堂.md)：供奉身份
- 与 [神手谷](../05-场景/神手谷.md)：驻地，拥有药田和房屋

## 关键事件

- 在树林中偶遇张均等人
- 点名要韩立和张铁两名记名弟子分别做炼药童子和采药弟子
- 带二人至神手谷
- 宣布韩立和张铁为记名弟子，传授医药知识和识文断字
- 一个月后传授无名口诀，严令不得外传
- 数年前救了王陆门主性命，被聘为供奉堂供奉
- 传授口诀后对二人不管不问，终日苦读"长生经"
- 考核韩立时察觉其体内能量后异常激动——眼中狂热、双手发颤、放声大笑、看韩立如"奇珍异宝"，甚至露出疯狂神情
- 韩立通过考核后成为其亲传弟子（身份高于一般正式弟子）
- 张铁口诀无成，但因根骨适合另一种心法同样过关，次日将另行传授
- 为韩立争取到只有高层才能享有的练功静室，每日提供珍贵药物辅助修炼
- 韩立冲关内伤后，墨大夫坐卧不宁、比韩立自己还紧张，治伤时"舍得用好药"
- 对韩立只传授无名口诀和医术，医术方面毫无保留，允许韩立随意翻看所有医术书籍
- 对张铁传授象甲功，明确告知此功的利弊
- 用珍贵药物时脸上流露出"难舍的神态"，说明其储备的药物极为宝贵
- 严禁韩立接触兵器，不准其学其他武功，韩立对此有抱怨
- 发现韩立因研究瓶子失眠导致修炼效率下降，狠狠训斥一顿。看出韩立对钱财的渴望，开出"每提高一层就翻倍给银子"的条件，重新激发韩立修炼热情
- 为了韩立专心修行，把整个神手谷对外封闭，连看病治人都在谷外进行，韩立日常衣食不让他操心
- 近年来病情更加严重，每日咳嗽频繁，对韩立修炼进度越发焦急。目光中除了珍爱外偶尔夹杂贪婪和渴望，韩立觉得他看自己"不像是在看一个活人，而像是在看一件东西"
- 韩立修炼停滞一年无提高，墨大夫焦黄面皮变得发白，但未责怪。称要下山找药材，两天后独自离开七玄门
- 韩立对墨大夫心底存了防范之意，且越来越强
- 韩立进入无名口诀第四层后，意外发现自己可以随意操纵体内真气的强弱，完全可以把真气控制成在第三层时的强度，以此瞒天过海
- 韩立在墨大夫回来前用瓶子催生了大批珍贵药材，按照配方调配出黄龙丹、清灵散、金髓丸、养精丹等稀世之药
- 韩立服用黄龙丹和金髓丸后当晚就冲破瓶颈练成口诀第四层
- 墨大夫回山谷了，气色比之前更加败坏，一副根本大限已至的模样。身后还跟着一位头戴黑色斗篷、全身被宽大绿袍罩得严严实实的神秘人物，身材异常高大魁梧
- 墨大夫把脉后脸色阴沉，对韩立不满意。脸孔变得诡异——灰败的脸上隐隐罩上一层淡淡的黑气。一改往日死板神情，现出一脸狠厉决断神色。阴阴一笑后身形一晃，整个人仿佛幽灵一样到了韩立身边。韩立脸色大变想举起手臂，但身上一麻动弹不得——墨大夫不知何时点了他的穴道
- 墨大夫伸手从韩立袖子里把铁筒搜了出来，用嘲笑、蔑视的目光看着韩立的表演。韩立渐渐闭上嘴巴，脸上变得安详下来
- 墨大夫全盘托出真相——他本名墨居仁，早年曾在越国岚州武林声名赫赫，绰号"鬼手"。中年时被亲信之人暗算下毒，虽然凭借医道高明控制住了伤势，却无法痊愈。为了怕仇家暗算，只好抛下原有的基业和家人销声匿迹。在某个神秘之处无意得到了一本奇书，按照上面方法恢复功力后却急速衰老。他现在活一天相当于普通人活十天的精力消耗。破解之道就是韩立修炼的"长春功"——只要有个练至第四层的人，帮他运功推拿，用长春气刺激秘穴，就可摆脱现在的困境。韩立具有罕见的"灵根"体质，墨大夫在他之前已找过数百名童子都无法修炼。墨大夫此次下山时被一个仇家认了出来，经过苦战后虽然击毙了对方，却也耗尽了我本来不多的精力，寿命也大大缩短了。即使他用尽全力也只能使自己再多活一年，叫我如何再等？韩立听完以后，神色如常，脸上没有丝毫被触动的迹象。可心里却波涛汹涌，完全没有表面看上去这样的胸有成竹、波澜不惊。他虽然早已预料到墨大夫对自己有很深的企图，但也没曾想会有这么大的内幕。对方的身世、经历、修炼的口决，无一不超出了他所想象的范围。
- 墨大夫用尸虫丸控制韩立，一年内韩立绝对安全，一年后无解药则内脏被吃光。墨大夫又提到韩立家人进行威胁
- 墨大夫对韩立的五毒水毒液感到后怕，毒液轻易腐蚀木板地面
- 墨大夫对韩立完全放任自流，只送药物不干涉行为——不敢过度限制自由怕适得其反
- 墨大夫身边有个头戴斗篷的神秘男子（"怪物"），绝对服从命令、体力惊人、从不开口说话
