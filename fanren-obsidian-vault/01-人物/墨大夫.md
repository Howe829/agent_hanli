# 墨大夫

## 基本信息

- 年龄：六十余岁
- 身份：七玄门大夫、供奉堂供奉
- 外貌：高高瘦瘦，面皮焦黄，长到披肩的白发
- 特征：不断咳嗽，看似体弱

## 身份/定义

七玄门内地位极高的医者。外表看似随时可能倒下，但在门内地位非同一般——张均认为其比堂主甚至副门主更值得尊敬。在神手谷内拥有独立的药田和居所。

## 当前已知关系

- 与 [韩立](./韩立.md)：韩立为其亲传弟子，韩立的修炼成果引发其异常狂热反应
- 与 [张铁](./张铁.md)：要其为采药弟子
- 与 [七玄门](../02-组织/七玄门.md)：门内大夫，供奉堂供奉，地位极高
- 与 [王陆](./王陆.md)：曾救王陆门主性命
- 与 [无名口诀](../03-功法/无名口诀.md)：传授者，对此口诀极为重视
- 与 [供奉堂](../02-组织/供奉堂.md)：供奉身份
- 与 [神手谷](../05-场景/神手谷.md)：驻地，拥有药田和房屋

## 关键事件

- 在树林中偶遇张均等人
- 点名要韩立和张铁两名记名弟子分别做炼药童子和采药弟子
- 带二人至神手谷
- 宣布韩立和张铁为记名弟子，传授医药知识和识文断字
- 一个月后传授无名口诀，严令不得外传
- 数年前救了王陆门主性命，被聘为供奉堂供奉
- 传授口诀后对二人不管不问，终日苦读"长生经"
- 考核韩立时察觉其体内能量后异常激动——眼中狂热、双手发颤、放声大笑、看韩立如"奇珍异宝"，甚至露出疯狂神情
- 韩立通过考核后成为其亲传弟子（身份高于一般正式弟子）
- 张铁口诀无成，但因根骨适合另一种心法同样过关，次日将另行传授
