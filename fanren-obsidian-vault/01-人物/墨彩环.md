# 墨彩环

## 基本信息

- 年龄：约十五六岁（当前，遗书时七岁，已过约十年）
- 身份：墨府二小姐，墨居仁与四夫人严氏之女
- 外貌：如花似玉，墨府三骄之一，十五六岁娇美女孩，与母亲有七八分相像
- 特征：声音清亮有活力，对娘亲撒娇，有不满会直说；精灵古怪，浑身散发这种味道；会装可爱、撒娇、泪水攻击三大绝招

## 身份/定义

墨居仁与四夫人严氏的亲生女儿。遗书中记载严氏生养一女墨彩环。当前在墨府中向严氏汇报暗舵事务，对暗舵收入减少和五娘独掌暗舵力量不满。

## 当前已知关系

- 与 [墨大夫](./墨大夫.md)（墨居仁）：父女关系
- 与 [严氏](./严氏.md)：母女关系，严氏对其溺爱异常
- 与 [五娘王氏](./五娘王氏.md)：对五娘独掌暗舵力量不满
- 与 [吴剑鸣](./吴剑鸣.md)：称其为"冒牌货"，讨厌他在后花园献殷勤
- 与 [惊蛟会](../02-组织/惊蛟会.md)：惊蛟会代理当家人之女
- 与 [韩立](./韩立.md)：正式见面后向韩立索要七八千两银子的"师兄见面礼"，被韩立用萦香丸打发；韩立将其从"爱慕候选名单"中划去
- 与 [萦香丸](../12-丹药/萦香丸.md)：韩立送的见面礼，彩环怀疑是迷药或春药
- 与 [吴剑鸣](./吴剑鸣.md)：称其为"冒牌货"，讨厌他在后花园献殷勤；吴剑鸣曾给她一万多两银票
- 与 [墨凤舞](./墨凤舞.md)：将萦香丸拿去给二姐检验

## 关键事件

- 向严氏汇报各暗舵解送银子的数额，暗舵收入比往年少了四分之一
- 抱怨暗舵负责人胆子越来越大，希望严氏整顿
- 对五娘独掌暗舵力量不满
- 在后花园碰到吴剑鸣对其献殷勤，觉得讨厌
- 严氏派她带韩立去后宅住宿
- 向韩立明目张胆索要"师兄见面礼"，开口要七八千两银子，并提及吴剑鸣曾给她一万多两
- 三大绝招（装可爱、撒娇、泪水攻击）对韩立无效——韩立因厉飞雨的类似表演已免疫
- 收到韩立的萦香丸后怀疑是迷药，表示需拿去给二姐检验
- 提出"以后有事找我帮忙，只要收些小小报酬"
- 韩立将其从"爱慕候选名单"中毫不犹豫划去
