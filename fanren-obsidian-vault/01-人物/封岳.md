# 封岳

## 基本信息

- 身份：[天阙堡](../02-组织/天阙堡.md)弟子，第一百三十三峰首座弟子
- 修为：炼气期巅峰（第十三层）
- 性格：狠辣狡诈，恶名昭著
- 标志性法器：[小刀符宝](../04-法宝/小刀符宝.md)、[黄罗伞](../04-法宝/黄罗伞.md)、风影靴

## 身份/定义

天阙堡中臭名昭著的狂人，多次在宗门任务中出手杀人越货。身法诡异迅速，拥有多件顶级法器，是禁地中被默认"屠戮者"之一。

## 首次登场

- [第三卷第一百八十七章 黄雀"封岳"](../08-章节/第三卷第一百八十七章%20黄雀"封岳".md)

## 当前已知关系

- 与 [天阙堡](../02-组织/天阙堡.md)：本门弟子，第一百三十三峰首座
- 与 [韩立](../01-人物/韩立.md)：敌对关系，被韩立以天雷子击杀
- 与 [白衣女](./白衣女.md)：击杀白衣女并夺走储物袋
- 与 [黄衫女](./黄衫女.md)：击杀黄衫女
- 与 [小刀符宝](../04-法宝/小刀符宝.md)：攻击符宝
- 与 [黄罗伞](../04-法宝/黄罗伞.md)：最重视的保命防御法器
- 与 [风影靴](../04-法宝/风影靴.md)：妖兽皮制成身法法器，被韩立获得

## 关键事件

1. 突然出现在韩立与白衣女的战斗中，击杀白衣女夺走储物袋
2. 与韩立展开激战，小刀符宝配合诡异身法令韩立苦战
3. 拥有顶级防御法器黄罗伞，轻松弹回金蚨子母刃
4. 被韩立以天雷子击杀，全身化为飞灰
5. 储物袋被天雷子摧毁，仅乌靴幸免
