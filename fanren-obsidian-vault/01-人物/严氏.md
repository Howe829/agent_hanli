# 严氏

## 基本信息

- 身份：墨居仁四夫人，墨居仁的表妹，惊蛟会代理当家人
- 外貌：声音低沉富有磁性
- 特征：生性沉稳，心计过人，有大家风范

## 身份/定义

墨居仁的第四任夫人，同时也是他的表妹。墨居仁离开时将惊蛟会权力大部分移交给她，遗书中明确标注"可以信任"。当前主持惊蛟会事务，但暗舵力量被五娘王氏独掌，无法插手。

## 首次登场

- [第二卷第一百零四章 情报](../08-章节/第二卷第一百零四章%20情报.md)（墨大夫遗书中首次提及）

## 当前已知关系

- 与 [墨大夫](./墨大夫.md)（墨居仁）：夫妻关系（四夫人），同时也是表妹，对墨居仁痴心不改
- 与 [墨彩环](./墨彩环.md)：母女关系，溺爱异常
- 与 [五娘王氏](./五娘王氏.md)：分权关系，五娘掌管暗舵力量
- 与 [吴剑鸣](./吴剑鸣.md)：已查明其冒牌身份，被迫虚伪拖延
- 与 [韩立](./韩立.md)：韩立以纹龙戒登门，严氏确认信物为真；韩立展示火弹术后严氏知道他是修仙者；双方就暖阳宝玉和谈
- 与 [二夫人李氏](./二夫人李氏.md)：姐妹关系，排行高于严氏，被称"二姐"
- 与 [三夫人刘氏](./三夫人刘氏.md)：姐妹关系
- 与 [惊蛟会](../02-组织/惊蛟会.md)：代理当家人
- 与 [墨府](../05-场景/墨府.md)：墨府主事人之一
- 与 [纹龙戒](../04-法宝/纹龙戒.md)：持有信物，龙纹与韩立戒指完美贴合
- 与 [千人醉](../12-丹药/千人醉.md)：用此迷药蜡烛试图制服韩立
- 与 [暖阳宝玉](../04-法宝/暖阳宝玉.md)：已交给心腹之人，有销毁后手

## 关键事件

- 墨居仁离开时将惊蛟会权力大部分移交给她
- 主持惊蛟会，但暗舵力量无法插手
- 已查明吴剑鸣是冒牌货并查明底细，但被迫牺牲大女儿名誉拖延时间
- 对墨居仁痴心不改，被女儿取笑
- 与墨彩环对话提及墨大夫离家将近十年、墨凤舞配出灵药
- 韩立以纹龙戒登门，严氏确认信物为真并要求看亲笔信
- 召集众夫人（二夫人李氏、三夫人刘氏、五夫人王氏）商议
- 众夫人用纹龙戒药粉调配现形水取出暗信
- 让五夫人探查四周确认无外人，强调韩立能避开二三十处暗哨非同寻常
- 安排韩立住宿、派墨彩环带路并警告不可捣乱
- 众夫人穿缟素孝服，韩立得知暗信揭露墨大夫死讯
- 用千人醉迷药蜡烛试图制服韩立，被韩立识破
- 确认韩立所述与暗信信息吻合，认为墨大夫之死不应由韩立负责
- 开出消灭五色门和独霸山庄换暖阳宝玉的条件，并威胁宝玉可被销毁
