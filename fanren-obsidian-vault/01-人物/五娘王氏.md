# 五娘王氏

## 基本信息

- 身份：墨居仁五夫人，原大夫人金氏贴身丫环
- 年龄：约二十六七岁
- 外貌：秀丽可人，一脸冷霜，冷艳少妇
- 特征：沉默寡言，对墨居仁痴心一片，未育子女；目光寒光闪动，是内力精湛的高手
- 权力：暗中握有秘密力量——暗舵

## 身份/定义

墨居仁的第五任夫人，原是大夫人金氏的贴身丫环。遗书中墨居仁标注"可绝对信任"。她暗中掌管暗舵力量，是惊蛟会最大的支柱。每月把暗舵大部分利银上交总舵。是众夫人中内力精湛的高手，负责探查和暗哨事务。能感知方圆二百米内是否有外人。

## 当前已知关系

- 与 [墨大夫](./墨大夫.md)（墨居仁）：夫妻关系（五夫人），对其痴心一片
- 与 [严氏](./严氏.md)：分权关系，五娘掌管暗舵，严氏主持明面事务
- 与 [暗舵](../02-组织/暗舵.md)：独掌暗舵力量
- 与 [惊蛟会](../02-组织/惊蛟会.md)：暗舵是惊蛟会最大的支柱
- 与 [韩立](./韩立.md)：韩立参拜五师母，王氏冷冰冰的声音让韩立感到寒意；让韩立讲述遇害经过；支持严氏的谈判决定
- 与 [纹龙戒](../04-法宝/纹龙戒.md)：持有信物，夹层内藏黑色药粉

## 关键事件

- 墨居仁离开时将暗舵交给她掌管
- 每月把暗舵大部分利银上交总舵
- 暗舵收入近年来减少四分之一以上
- 正式出场，韩立发现她是内力精湛的高手，目光寒光闪动
- 确认方圆二百米内无外人后，严氏决定取出暗信
- 用内功烘干显形水涂抹后的信纸
- 让韩立讲述墨大夫遇害经过
- 在谈判中支持严氏的决定，"不会有任何意见"
