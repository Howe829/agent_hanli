# 陈师妹

## 基本信息

- 身份：[黄枫谷](../02-组织/黄枫谷.md)低阶女弟子
- 外貌：妙龄女子，娇美面容，肌肤洁白丰满
- 修为：炼气期（被[陆师兄](./陆师兄.md)控制，无法反抗）

## 身份/定义

黄枫谷低阶女弟子，"[陆师兄](./陆师兄.md)"的情侣。从[血禁试炼](../09-关系/血禁试炼.md)归来后被陆师兄控制，成为其"先奸后杀"的目标。

## 首次登场

- [第二卷第一百六十五章 夜遇](../08-章节/第二卷第一百六十五章%20夜遇.md)

## 当前已知关系

- 与 [陆师兄](./陆师兄.md)：表面情侣关系，陆师兄在禁地归来后突然翻脸，欲先奸后杀夺其筑基丹
- 与 [韩立](../01-人物/韩立.md)：韩立偷见其被陆师兄控制；陆师兄被杀后，合欢丹发作的陈师妹扑向韩立，被韩立以定神符再次束缚
- 与 [陈家家主](../01-人物/陈家家主.md)（待建页）：陈家独生女，身份显贵，是陆师兄必杀的原因之一
- 与 [陈师兄](./陈师兄.md)：陈氏家族大公子，其大哥
- 与 [黄枫谷](../02-组织/黄枫谷.md)：本门女弟子
- 与 [筑基丹](../12-丹药/筑基丹.md)：拥有一枚筑基丹（红色小木盒中），是陆师兄杀她的重要目标
- 与 [合欢丹](../12-丹药/合欢丹.md)：被陆师兄喂食合欢丹，情欲发作
- 与 [定神符](../06-符箓/定神符.md)：先后被陆师兄以风缚术、韩立以定神术束缚

## 关键事件

1. 在[血禁试炼](../09-关系/血禁试炼.md)中与陆师兄一同存活归来，并获得一枚筑基丹
2. 被陆师兄控制后带到太岳山脉外围的石洞外
3. 陆师兄撕扯其衣衫欲先奸后杀，并给她喂食[合欢丹](../12-丹药/合欢丹.md)
4. 陆师兄从其身上搜出储物袋，找到装筑基丹的红色小木盒，欲两枚筑基丹一起服用
5. 陆师兄自语暴露动机：与董妮子有约，需与陈师妹断绝；又恐陈家报复，故杀人灭口
6. 被陆师兄以风缚术束缚无法动弹，合欢丹药力发作后神志不清
7. 陆师兄被韩立击杀后，风缚术时效已过，恢复行动能力的陈师妹扑向韩立求欢
8. 韩立以定神符再次将其束缚
9. 血色试炼中进入禁地，与大哥[陈师兄](./陈师兄.md)同行
10. 提及[陆师兄](./陆师兄.md)被杀之事，回忆起韩立救她时的羞恼回忆
