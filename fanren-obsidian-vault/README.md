# 凡人修仙传 Obsidian Wiki

这是一个基于 `LLM Wiki` 思路搭建的 Obsidian 知识库。

## 分层

- 原始资料：`../resources/`
- Wiki 层：当前目录
- 维护规则：[AGENTS.md](./AGENTS.md)

## 目录结构

- `01-人物/` — 人物实体页
- `02-组织/` — 门派、势力、家族、团体
- `03-功法/` — 功法、口诀、秘术
- `04-法宝/` — 法宝、器物、关键道具
- `05-场景/` — 村庄、城市、宗门、洞府、山脉等地点
- `06-符箓/` — 符箓与符道相关实体
- `07-阵法/` — 阵法与禁制
- `08-章节/` — 章节摘要页
- `09-关系/` — 跨章节关系总览、关系网页、专题梳理
- `10-灵虫/` — 灵虫、异虫、育虫体系
- `11-妖兽/` — 妖兽、灵兽、真灵后裔
- `12-丹药/` — 丹药、药丸、灵液、炼丹产物
