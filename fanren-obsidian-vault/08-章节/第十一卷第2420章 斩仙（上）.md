# 第十一卷第2420章 斩仙（上）

**章节**: 第十一卷第2420章 斩仙（上）
**摘要**: 马良以[[万灵血玺]]化八条五爪血龙攻击[[韩立]]二人。[[蟹道人]]化为黄金巨蟹抵挡两条血龙。韩立以[[青蟠剑阵]]幻化青色蟠龙对抗血龙，但因消耗巨大只能勉强维持。韩立以[[元合五极山]]抵挡血印虚影，再以[[玄天斩灵剑]]发动致命一击，一击毁掉马良的[[斩元仙剑]]，令马良喷血重伤。韩立同时施展[[涅槃圣体]]三阶变身化为三头六臂的狰狞魔神。

## 新增关系

- [[斩元仙剑]] 与 [[马良]]: 马良的重要随身宝物，被玄天斩灵剑一击毁掉，令马良极为震怒。
- [[韩立]] 与 [[梵圣法相]]: 韩立将梵圣法相融入体内作为变身的基础。
- [[韩立]] 与 真灵法相: 韩立体内可飞出天龙、真凤、青鸾等真灵法相虚影融入自身增强战力。
