# 第十一卷第2392章 失踪

**章节**: 第十一卷第2392章 失踪
**摘要**: 六翼和冰凤以[[寄附神魂]]的仙界秘术将神魂完整寄附在两名角蚩族修炼者身上，暂时摆脱马良追杀。六翼提及此秘术来自[[金阙玉书]]中的一页。半月后马良追至角蚩族另一主城，与角蚩族六大乘老祖展开大战，四名大乘陨落、两名重伤逃遁。角蚩族高层以玄天残宝击伤马良，后借上古契约召唤三头[[上古真灵]]（[[蹄龙]]、[[泰雀]]、[[阳鹿]]）与马良再战。数日后双方全部消失无踪，马良与三头真灵均不翼而飞。六翼和冰凤趁机借助跨大陆传送阵返回风元大陆。韩立亦通过传送阵抵达风元大陆，受[[明尊]]相邀会面。

## 新增关系

- [[六翼]] 与 [[金阙玉书]]: 六翼早年误入异族洞府，得金阙玉书一页，中学会仙界秘术"寄附神魂"。
- [[六翼]] 与 [[韩立]]: 冰凤提议找韩立解除马良留在身上的神魂印记，六翼大怒拒绝，暗示六翼与韩立之间有深刻矛盾。
- [[马良]] 与 [[角蚩族六大乘老祖]]: 马良与六名角蚩族大乘大战大半日，击杀四名、重伤两名，但自身也被角蚩族玄天残宝击伤。
- [[角蚩族]] 与 [[上古真灵]]（蹄龙、泰雀、阳鹿）: 角蚩族以玄天之宝之力立下上古契约，可从其他空间召唤供奉的上古真灵参战。
- [[马良]] 与 [[上古真灵]]: 马良与三头上古真灵激战数日后全部消失，去向不明。

## 伏笔

- 六翼提及韩立曾斩杀"螟虫之母"，暗示韩立在灵界的声望。
- 马良与三头真灵同时消失，暗示马良使用了空间秘宝将其拖入异空间。
- 六翼和冰凤返回风元大陆，可能与韩立产生正面冲突。
