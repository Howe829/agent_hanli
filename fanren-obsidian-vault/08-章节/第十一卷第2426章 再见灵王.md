# 第十一卷第2426章 再见灵王

**章节**: 第十一卷第2426章 再见灵王
**摘要**: 韩立在青元宫密室中花费半日，以融元仙术将掌天瓶仿制品完整融入本体掌天瓶中，初步获得催动此宝的能力。随后通过蟹道人查证，确认手中残缺命牌主人在灵族灵域附近，韩立判断其与灵王有关。数月后，韩立驾墨灵圣舟抵达灵族圣地伏灵山，直接面见灵王。灵王引出被封印在晶莹冰峰中的俊美青年真仙，此仙正是命牌主人。灵王透露此仙身躯已更换为灵界真仙之躯，法力元神与肉身封闭一体，强横至极即使用玄天之宝也无法伤及。

## 新增关系

- [[韩立]] 与 [[掌天瓶]]: 韩立以融元仙术将仿制品融入掌天瓶本体，初步获得催动此宝之法。
- [[韩立]] 与 [[灵王]]: 韩立驾舟直接拜访灵王伏灵山，以命牌探询其主人身份。
- [[灵王]] 与 [[封印仙人]]: 灵王以封印之法镇压此仙，并以本命之火慢慢炼化对方真仙之躯。
- [[封印仙人]] 与 [[九元观]]: 此仙在仙界时逃避九元观追杀，与掌天瓶失窃事件有关。
- [[掌天瓶]] 与 [[封印仙人]]: 此仙曾盗得掌天瓶并施加强制封印，后在掉落下界过程中瓶灵脱壳逃走。

## 伏笔

- 灵王本体实为其以法术召唤出的白色小人，老者本身并非其真正形态。
- 封印仙人的身躯更换为灵界真仙之躯后强横至极，韩立后续需要寻找办法斩杀此仙。
- 韩立提及"新近炼成了一件宝物"，暗示后续将有新宝物登场用于杀仙。
