# 第十一卷第2435章 人族之变

**章节**: 第十一卷第2435章 人族之变
**摘要**: 韩立吞服广灵道果后离去，金长老向龙族众人透露韩立神识虽强大但根基已隐患重重，若不妥善应对，再过几百年连性命都保不住。此时轩辕族轩辕杰赶到，让龙族众人将韩立之事搁置。一年后韩立返回人族无涯海青元宫闭关。两百年间人族发生巨变：冰魄仙子以大乘老祖身份回归，木族等弱小种族依附人族，夜叉等族迁移，人族和妖族实力急剧膨胀，所有变化源头均来自青元宫。又两百年后，韩立发现炼神术弊端，以真魂丹交换从魔界封印之地的一名前辈处获得可直通仙界的宝符。三百年后，白果儿向韩立献上昊阴之石和寒魄神通修炼成果。

## 新增关系

- [[金长老]] 与 [[韩立]]: 金长老以天赋秘术探查发现韩立神识根基隐患重重，但并未提醒韩立。
- [[韩立]] 与 [[人族]]: 韩立闭关期间，青元宫流出大量顶阶功法和珍稀宝物，使人族和妖族实力急剧膨胀，人族一跃成为风元大陆最引人注意的种族之一。
- [[韩立]] 与 [[炼神术]]: 韩立闭关两百年后发现炼神术弊端（神识隐患），魔光和火须子也束手无策，最终再次前往魔界寻求解决办法。
- [[韩立]] 与 [[封印之地前辈]]: 韩立在魔界封印之地以真魂丹换取对方手中的直通仙界宝符及炼神术第三层修炼之法。
- [[轩辕族]] 与 [[龙族]]: 轩辕族轩辕杰作为上古轩辕一族之人参加道果大会，令龙族众人震惊。

## 伏笔

- 韩立神识之力的隐患是炼神术造成的，后续需要寻找解决办法。
- 直通仙界的宝符可能是韩立最终飞升的关键。
- 白果儿修炼的寒魄神通和昊阴之石的用途尚未揭示。
