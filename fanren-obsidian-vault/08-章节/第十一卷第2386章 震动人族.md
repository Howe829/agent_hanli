# 第十一卷第2386章 震动人族

**章节**: 第十一卷第2386章 震动人族
**摘要**: 绿灵族三大强者及古树祖灵被一人族大乘灭杀的消息传遍小灵天，各族震惊。人族四名合体修士在石殿中紧急商议，确认此人大乘身份后决定迎接。月仙子（南宫婉）飞剑传书表示愿共同出面对接。韩立驾[[墨灵圣舟]]抵达朱果儿母亲[[凌飞仙]]的洞府，朱果儿惊喜归家。

## 新增关系

- [[韩立]] 与 [[绿灵族]]: 韩立灭杀绿灵族三大强者及古树祖灵，此消息震动整个小灵天。
- [[南宫婉]] 与 [[人族]]: 作为"月仙子"，南宫婉被公认为小灵天人族第一强者，修为已达合体大成。
- [[凌飞仙]] 与 [[朱果儿]]: 母女关系，凌飞仙修为已达炼虚境界。
- [[韩立]] 与 [[凌飞仙]]: 韩立救下朱果儿后顺道送其回家，初次见面。

## 伏笔

- 人族四名合体修士对突然出现的"人族大乘"既期待又忌惮，暗藏防备之心。
- 南宫婉正在闭关修炼"十分重要的秘术"，暂无法出关。
- 小灵天无人族大乘的传说可能被打破。
