# 第十一卷第2340章 钥匙

**章节**: 第十一卷第2340章 钥匙
**摘要**: 万月山脉中各方势力聚集。碧影得知齐云山脉附近八国和十九个宗门全部诡异地消失，推测是大乘期血道强者进行大规模血祭所致，命令下属通报啼血门和风蛇族。血鹤城中，韩立收到虚天鼎感应后带着花石老祖和血魄前往万月山脉。萧冥得知韩立动向，与万花夫人和清平道人讨论对策，认为没有钥匙韩立无法进入天鼎宫。血魄向韩立讲述当年冰魄本体进入天鼎宫的经过，以及虚天鼎实为仿制钥匙的真相。

## 新增关系

- [[血魄]] 与 [[冰魄]]: 血魄是冰魄的分身，冰魄本体当年进入天鼎宫后被封困其中。
- [[虚天鼎]] 与 [[金阙玉书]]: 虚天鼎是用金阙玉书秘术炼制的仿制钥匙，效果只有原物的小半。
- [[碧影]] 与 [[啼血门]]、[[风蛇族]]: 碧影将八国消失之事通报啼血门和风蛇族追查。
- [[血骨门]] 与 [[天鼎宫]]: 血骨门手中保留有一两柄天鼎宫钥匙。

## 伏笔

- 八国和十九宗门全部消失，疑似大乘期血道强者进行大规模血祭。
- 冰魄本体被困天鼎宫，韩立曾答应将其救出。
- 持有钥匙者众多，进入天鼎宫前必有一场厮杀。
