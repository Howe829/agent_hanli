# 第十一卷第2427章 下落

**章节**: 第十一卷第2427章 下落
**摘要**: 韩立要求搜魂被封印仙人，灵王提出条件：韩立需接下其三招方可自由处置此仙。二人到伏灵山山腹大厅对决，韩立以玄天斩灵剑轻松接下灵王前两招，灵王心服口服将封印仙人交由韩立处置。韩立成功搜魂，但发现对方大部分关键记忆被神秘能量封锁，触碰后仙人头颅爆裂身亡。韩立从残留记忆中得知掌天瓶分落两界的原因及瓶灵藏在魔界的消息，并从此仙身上抽取一滴灵血用于追踪之术。

## 新增关系

- [[韩立]] 与 [[灵王]]: 韩立接下灵王两招后获得封印仙人的处置权。
- [[封印仙人]] 与 [[掌天瓶]]: 此仙曾利用大挪移符逃遁，传送时受神秘力量影响掉入灵界，掌天瓶瓶灵趁势施展天赋神通一分为二脱壳而走，分别掉入不同界面。
- [[封印仙人]] 与 [[瓶灵]]: 此仙曾对瓶灵施展追踪法术，确定瓶灵隐藏在魔界中。
- [[封印仙人]] 与 [[广寒界]]: 此仙曾悄悄潜入广寒界，寻找对其凝固真仙之躯有用的灵药（即韩立当日看到的银色莲蓬）。

## 伏笔

- 韩立从此仙灵血中获得追踪之术，可定位瓶灵在魔界中的位置。
- 掌天瓶瓶灵藏在魔界，韩立决定前往魔界寻找。
- 章节末尾一枚银灿灿鳞片从韩立袖中飞出，与龙岛相关。
