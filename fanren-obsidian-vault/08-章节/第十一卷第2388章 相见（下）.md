# 第十一卷第2388章 相见（下）

**章节**: 第十一卷第2388章 相见（下）
**摘要**: 韩立与苦寻多年的双修伴侣[[南宫婉]]（月仙子）终于重逢。南宫婉讲述当年在空间节点偷渡灵界时，遭遇[[罗睺]]和[[百头虫]]两败俱伤的争斗，被波及落入小灵天，侥幸获得两头真灵晶核的庞大精元，方能在灵气匮乏的小灵天中于不到两千年内修炼至合体大成。韩立承诺回灵界后有手段助南宫婉渡大乘之劫，并同意带领人族后辈一同返回。

## 新增关系

- [[韩立]] 与 [[南宫婉]]: 双修伴侣，分别多年后终于在小灵天重逢。
- [[南宫婉]] 与 [[罗睺]]: 罗睺在空间节点中与百头虫争斗两败俱伤而陨落，其晶核被南宫婉所得。
- [[南宫婉]] 与 [[百头虫]]: 百头虫为上古真灵，陨落时与罗睺同坠小灵天，晶核被南宫婉所得。
- [[南宫婉]] 与 [[朱果儿]]: 南宫婉收朱果儿为弟子，传授轮回素女功。
- [[南宫婉]] 与 [[凌飞仙]]: 南宫婉收凌飞仙为记名弟子，以真灵之晶助其快速提升至炼虚境界，为其护法之用。
- [[韩立]] 与 [[元瑶]]: 韩立在冥河之地曾遇元瑶，南宫婉闻之调笑。
- [[韩立]] 与 [[紫灵]]: 韩立在魔界曾遇紫灵，南宫婉闻之调笑。

## 伏笔

- 韩立提及有"逆天手段"可助南宫婉渡大乘之劫多几成把握。
- 韩立进入小灵天的通道尚存且被法阵遮蔽，短时间内不会溃散，可继续用于返回灵界。
- 罗睺与百头虫两大真灵在空间节点中争斗陨落，此事暗示灵界空间节点存在重大隐患。
