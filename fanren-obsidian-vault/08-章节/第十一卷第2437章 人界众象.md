# 第十一卷第2437章 人界众象

**章节**: 第十一卷第2437章 人界众象
**摘要**: 韩立分魂巡视人界。先见到大晋上空数百名正邪修士的厮杀，感慨数千年物是人非。随后无视禁制闯入昆吾山，发现此山早已物是人非、宝物被挖掘一空，韩立以青色巨手将整座昆吾山拍毁，使其凭空消失，此事成为大晋十大不可思议传说之一。后来到乱星海天星城，在凌玉灵的千年寿诞之日现身星宫大殿，与凌玉灵半日长谈，打听到昔日旧人消息——田琴儿为突破化神强行度劫陨落、石坚元婴期同归于尽但大衍神君道统兴盛、黄枫谷落云宗皆有惊人发展。韩立随后离去，希望将来在灵界再见凌玉灵。

## 新增关系

- [[韩立]] 与 [[昆吾山]]: 韩立重返昆吾山发现物是人非，以神通将其彻底拍毁
- [[韩立]] 与 [[凌玉灵]]: 多年后再会，凌玉灵已进阶化神并寿元突破人界限制，成为乱星海唯一化神期修士
- [[田琴儿]] 与 [[化神]]: 两千余年前为突破化神强行度劫未成，化为灰烬，但神魂或有轮回转世机会
- [[石坚]] 与 [[大衍神君]]: 石坚继承了大衍神君道统，虽已陨落但道统越发兴盛
- [[黄枫谷]] 与 [[天南]]: 数千年间接连收下天才弟子修成元婴，成为天南不小的一大宗门
- [[落云宗]] 与 [[云梦山脉]]: 因韩立留下的班底，元婴长老层出不穷，势力雄霸整个云梦山脉

## 伏笔
