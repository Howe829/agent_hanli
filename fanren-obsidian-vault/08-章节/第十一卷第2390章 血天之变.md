# 第十一卷第2390章 血天之变

**章节**: 第十一卷第2390章 血天之变
**摘要**: 墨灵圣舟返回灵界，通道随即崩溃。韩立与南宫婉惊叹灵界灵气精纯远超小灵天。圣舟抵达[[血天大陆]]，韩立从[[赫连商盟]]分盟负责人处得知[[碧影]]已陨落，多位大乘中强者被一"绝世凶魔"以血祭手段屠杀。此凶魔疑似仙界降临之人，因其施展神通时曾触发[[法则之链]]。凶魔已血祭血天大陆西部十余处，后杀入[[血痕宗]]屠杀两名大乘老祖，激活跨大陆法阵传送至[[雷鸣大陆]]追杀[[六翼]]和[[冰凤]]。

## 新增关系

- [[韩立]] 与 [[碧影]]: 碧影已陨落于"绝世凶魔"之手，韩立闻讯震惊。
- [[绝世凶魔（马良）]] 与 [[血天大陆]]: 凶魔在血天大陆西部进行十余处大规模血祭，几乎将西部生灵一扫而空。
- [[绝世凶魔（马良）]] 与 [[血痕宗]]: 凶魔杀入血痕宗，屠杀两名大乘老祖和数千高中阶弟子后传送逃离。
- [[绝世凶魔（马良）]] 与 [[法则之链]]: 凶魔施展大神通时触发法则之链贯穿全身、禁锢大半法力，此为其为仙界仙人的重要证据。
- [[六翼]] 与 [[冰凤]]: 二人被凶魔从血天大陆一路追杀至雷鸣大陆，元气大损、疲于奔命。

## 伏笔

- "绝世凶魔"极可能是仙界降临的真仙，其身份和目的成谜。
- 凶魔突然放弃血祭转而紧追六翼和冰凤，暗示二者与其有特殊关联。
- 通道崩溃后韩立不知何时才能再次前往小灵天。
