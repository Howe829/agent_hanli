# 第十一卷第2389章 威震诸族

**章节**: 第十一卷第2389章 威震诸族
**摘要**: 韩立召见四名人族合体修士，安排撤离小灵天事宜：选拔百余名最出色后辈带回灵界，韩立承诺不定期派人返回带走更多子弟。韩立与南宫婉踏遍小灵天各异族区域，以绝对实力斩杀或降服各族强者，[[风灵族]]最强者被一击灭杀，[[巨螂族]]第一强者"罡靳"被斩杀，[[月牙族]]大阵被破数千族人被杀，[[夜眠族]]大长老主动臣服。数月后墨灵圣舟载人通过通道返回灵界。

## 新增关系

- [[韩立]] 与 [[风灵族]]: 韩立一击斩杀风灵族最强者（近乎大乘境界），此族屈服。
- [[韩立]] 与 [[巨螂族]]: 韩立以金色雷球化弥天金网灭杀巨螂虫群，并以剑光斩杀第一强者"罡靳"。
- [[韩立]] 与 [[月牙族]]: 韩立以一人之力破去月牙族大阵，斩杀数千族人及三大长老肉身，此族溃败。
- [[韩立]] 与 [[夜眠族]]: 夜眠族大长老主动向韩立臣服，发誓有生之年不出沼泽。
- [[韩立]] 与 [[绿灵族]]: 绿灵族已被吓得远远躲开，不敢接近巨舟万里之内。
- [[朱果儿]] 与 [[南宫婉]]: 南宫婉正式收朱果儿为弟子。

## 伏笔

- 韩立表示会留下"几样重宝"供人族防备异族，为小灵天人族留下后手。
- 通道下次开启不知要等到何时，暗示此通道有时间限制。
