# 第十一卷第2369章 阴司五王

**章节**: 第十一卷第2369章 阴司五王
**摘要**: 两个月后，强者之战正式开始。韩立在要塞与碧影、文心凤、雷元汇合，血煞尚未赶到。碧影带领众人驾驭巨型飞行法器前往分界线处，在约定地点的五座山峰附近开始布置巨型法阵和临时要塞。碧影向众人介绍强者之战规则：五人对五人在五座山峰对决，双方阵法师布置防护禁制，说出"认输"或分出生死即结束。对方为冥界阴司十王中的五位鬼王。同时，冥界一方的五名黑影也在白骨山中商议此战，其中提到冥熊老大因和夜鬼一族争夺阴界而无法分身，五阴锁心锤等本命法器也首次提及。

## 新增关系

- [[韩立]] 与 [[雷元]]: 同为商盟一方的出战人选，在要塞汇合。
- [[雷元]] 与 [[碧影]]: 雷元为赫连商盟雷鸣大陆负责人，地位与碧影相等。
- [[冥熊]] 与 [[冥雄]]: 冥熊老大神通不下于真仙，正因与夜鬼一族争夺阴界而无法分身参加此战。
- [[阴司十王]] 与 [[冥雄]]: 阴司十王受冥雄老大统率。
- [[七窍王]] 与 [[凶司王]]: 同为此次出战的五名鬼王成员。
- [[碧影]] 与 [[血煞]]: 血煞为商盟一方出战人选，此时尚未赶到。

## 伏笔

- 冥界一方声称胜算七八成以上，但担忧对方战后是否会遵守约定撤出。
- 七窍王被特别问及"后手"是否准备好，暗示其有额外安排。
- 文心凤神通对鬼物有几分克制之用。
