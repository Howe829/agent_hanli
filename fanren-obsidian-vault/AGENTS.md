# 凡人修仙传 LLM Wiki 维护规则

## 目标

本仓库是《凡人修仙传》的 Obsidian 知识库，由 LLM 按照 `LLM Wiki` 思路持续维护。

维护目标：

- 围绕人物、组织、功法、法宝、场景、符箓、阵法建立稳定的实体页
- 章节摄入后，优先更新已有实体页，而不是重复创建碎片页
- 关系、冲突、首次登场、重要转折必须可追溯到章节来源
- `resources/` 是原始资料层，视为只读 source of truth

## 目录约定

- `00-总览/`：总览页、索引页、关系图、维护日志
- `01-人物/`：人物实体页
- `02-组织/`：门派、势力、家族、团体
- `03-功法/`：功法、口诀、秘术
- `04-法宝/`：法宝、器物、关键道具
- `05-场景/`：村庄、城市、宗门、洞府、山脉等地点
- `06-符箓/`：符箓与符道相关实体
- `07-阵法/`：阵法与禁制
- `08-章节/`：章节摘要、章节关系页、章节级事件页
- `09-关系/`：跨章节关系页、关系网页、专题梳理
- `10-灵虫/`：灵虫、异虫、育虫体系相关实体
- `11-妖兽/`：妖兽、灵兽、真灵后裔等兽类实体
- `12-丹药/`：丹药、药丸、灵液与炼丹产物相关实体

## 页面写法

实体页默认使用以下结构：

1. 基本信息
2. 身份/定义
3. 首次登场
4. 当前已知关系
5. 关键事件
6. 相关条目
7. 来源

章节页默认使用以下结构：

1. 章节信息
2. 摘要
3. 登场实体
4. 新增关系
5. 对后续剧情的伏笔
6. 来源

章节页中的“登场实体”必须全部满足以下二选一：

- 已经建立可点击页面
- 明确放入“未建页实体”小节，并写明为什么暂不建页

## 命名规则

- 人物页直接使用人物名，如 `韩立.md`
- 未知姓名但重要的角色，可以用稳定描述命名，如 `韩立三叔.md`
- 场景页使用故事内最稳定的称呼，如 `山边小村.md`
- 章节页使用 `第一卷第01章 山边小村.md` 这种格式

## 维护规则

- 不修改 `resources/` 下原文
- 新摄入章节时，先读章节页，再更新对应实体页和总览页
- 如实体尚无正式名称，但后文会揭示，不提前臆造
- 如信息不确定，明确写“当前仅根据某章节可知”
- 关系分为：亲属、师徒、同门、敌对、交易、从属、影响、伏笔
- 及时更新相关实体的引用条目和来源
- 不把“原文明确陈述”和“基于语境推断”混写在同一句里；推断要显式标注为“可推知”“可能”“当前看更像”
- 单章信息不足以支持稳定设定时，不上升为泛化结论，例如“负责某类事务”“长期熟悉某地”“具有固定职能”
- 每摄入一章后，必须同步检查并更新：
  - `index.md`
  - `log.md`
  - `Home.md`
  - 所有被影响的实体页 `相关条目` 与 `来源`
- 每完成一个整十章节点（第10、20、30章……）后，必须触发一次 lint/review，回顾最近十章，检查是否有已经稳定出现但仍未建页、未归类或被错误归类的实体与分类
- 每完成一整卷的当前整理范围后，必须触发一次 lint/review，回顾本卷所有已整理章节，检查是否存在遗漏实体、遗漏分类、错误归类、断链、索引缺项或证据不足却被写成定论的内容
- 新增实体页前先检查是否只是现有页面中的一条属性；避免为了凑页数创建信息量过低的碎片页
- 章节摘要优先写“本章直接发生了什么”，其次才写背景补叙和叙事作用，避免摘要被世界观说明吞掉
- 组织、人物、场景页中的“当前已知信息”只写文本能直接支撑的事实；解释性判断放到“叙事作用”或单独的“当前判断”
- 不把 Obsidian 本地使用状态文件当作知识库内容的一部分进行维护或审查；如无必要，不主动编辑 `.obsidian/workspace.json`

## 章节摄入检查清单

每次新增章节后，至少完成以下检查：

1. 章节页是否覆盖了本章主事件，而不只是背景设定
2. 新增实体是否都在索引页可发现
3. 所有新增关系是否能回指到具体章节原文
4. 是否出现了未建页但被当作正式实体列出的对象
5. 是否有超出原文证据范围的角色职责、组织机制或地理关系推断
6. 已有实体页是否补充了新章节来源与相关条目

## 阶段性 lint 触发器

- 整十章节回顾：每整理完第10、20、30章等整十章节点后，回顾最近十章，重点检查遗漏分类、遗漏实体页、错误归类、索引缺项与交叉引用缺失
- 整卷回顾：每整理完一整卷当前计划范围后，回顾本卷全部已整理章节，重点检查分类体系是否需要扩充、既有分类是否有误、章节页与实体页的证据链是否完整
- 阶段性回顾属于 `LLM Wiki` 工作流中的 `lint` 阶段，不是可选步骤；应在 `log.md` 记录为独立的 lint 或 review 条目

## 证据标记

- 直接事实：原文明确写出，可直接陈述
- 当前判断：依据当前已整理章节做出的整理性结论，必须保守措辞
- 待验证：后续章节可能修正或补全的信息
