# 彩霞山

## 基本信息

- 类型：山脉
- 原名：落凤山
- 规模：镜州境内第二大山，方圆十几里，大小山峰十几个
- 主峰：落日峰

## 首次登场

- 见第一卷相关章节

## 身份/定义

七玄门总门所在地。原名落凤山，相传古时五色彩凤落下化成此山。因落日时美景如彩霞笼罩，被改称彩霞山。被七玄门占据后外人不得随意进入。

## 当前已知关系

- 与 [七玄门](../02-组织/七玄门.md)：门派总门驻地，所有山峰被各分堂占据
- 与 [仙霞山](./仙霞山.md)：原文第二章称"仙霞山"，第三章此处称"彩霞山"，七玄门驻地，当前判断为同一山的不同称呼
- 与 [落日峰](./落日峰.md)：彩霞山主峰，总堂所在地
- 与 [百莽山](./百莽山.md)：镜州第一大山，仅提及
- 与 [清客院](./清客院.md)：位于彩霞山上较矮山峰处
