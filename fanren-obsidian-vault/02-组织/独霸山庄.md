# 独霸山庄

## 基本信息

- 类型：江湖帮派
- 规模：大型帮派

## 身份/定义

岚州三大霸主之一的江湖帮派，与惊蛟会、五色门鼎立。庄主欧阳飞天与墨居仁同辈，雄心勃勃想称霸整个岚州，采取先弱后强策略——先吃掉惊蛟会，再对付五色门。

- 与 [欧阳飞天](../01-人物/欧阳飞天.md)：庄主
- 与 [吴剑鸣](../01-人物/吴剑鸣.md)：欧阳飞天派七弟子进入墨府
- 与 [五色门](./五色门.md)：同为岚州三大霸主
- 与 [韩立](../01-人物/韩立.md)：韩立受严氏委托击杀庄主欧阳飞天

## 关键事件

- 几年前鼓动马空天和赵坤分裂惊蛟会，被严氏识破处决
- 大军压进，打得惊蛟会节节败退固守嘉元城
- 派七弟子吴剑鸣带假遗书和信物进入墨府
- 严氏要求韩立击杀独霸山庄庄主欧阳飞天作为交换暖阳宝玉的条件
- 韩立拒绝对抗整个帮会，改为只刺杀庄主欧阳飞天一人
- 韩立骑马十日赶到独霸山庄，趁欧阳飞天赏月时用剑符击杀
