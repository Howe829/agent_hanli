# 黄枫谷

## 基本信息

- 类型：修仙门派
- 所属：七大仙派之一
- 掌门：钟灵道

## 身份/定义

黄枫谷是修仙界七大仙派之一，韩立通过升仙会拜入的门派。作为修仙门派，不是以入门早晚论资排辈，而是看境界深浅划分身份，以能者为师。

## 首次登场

- [第二卷第一百二十七章 灵根之说](../08-章节/第二卷第一百二十七章%20灵根之说.md)（万小山口述越国七大门派时首次提及）

## 当前已知信息

- 是七大仙派之一，钟灵道为首
- 弟子分低阶弟子和筑基期弟子等不同等级
- 基础功法练至十层可离开新弟子住处，搬到玄坤山居住
- 门内设有传功阁、百机堂、岳麓殿等重要建筑
- 低阶弟子每年通过各种工作约挣二三十块灵石
- 普通弟子平均收入约每月三块灵石
- 每十年一次大开山门招收新弟子
- 岳麓殿内有传说一位结丹期师叔祖常年闭关坐镇

## 当前已知关系

- 与 [韩立](../01-人物/韩立.md)：韩立通过升仙令入门的新进弟子
- 与 [钟灵道](../01-人物/钟灵道.md)：掌门
- 与 [百机堂](./百机堂.md)：门内负责杂务任务分配的建筑
- 与 [传功阁](./传功阁.md)：门内负责功法传授的建筑
- 与 [岳麓殿](./岳麓殿.md)：门内法器、丹药配方收藏处
- 与 [掩月宗](../02-组织/掩月宗.md)：同为七大仙派，掩月宗实力最强

## 关键事件

1. 韩立通过升仙令拜入黄枫谷
2. 韩立被分配到百药园管草，作为门内杂务工作
3. 黄枫谷十年一次大开山门，招收到慕容兄弟等天才弟子
4. 掩月宗在新收弟子中发现天灵根小姑娘，让钟灵道受挫
