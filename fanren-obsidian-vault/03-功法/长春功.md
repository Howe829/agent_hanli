# 长春功

## 基本信息

- 类型：修仙功法
- 传授者：墨大夫（原称"无名口诀"）
- 特点：要求年少之人从头开始修炼，必须具有"灵根"体质

## 身份/定义

"无名口诀"的真正名称。墨大夫从一本奇书中获得，能恢复功力并延缓衰老。修炼至第四层可帮墨大夫运功推拿，用长春气刺激秘穴，摆脱其困境。要求修炼者必须具有"灵根"体质，墨大夫在此前已找过数百名童子都无法修炼。

## 当前已知关系

- 与 [无名口诀](./无名口诀.md)：同名同物，"无名口诀"是墨大夫对韩立使用的称呼，"长春功"是正式名称
- 与 [墨大夫](../01-人物/墨大夫.md)：墨大夫从一本奇书中获得此功，是破解其衰老困境的关键
- 与 [韩立](../01-人物/韩立.md)：修炼者，具有罕见的"灵根"体质

## 当前已知信息

- 墨大夫对此口诀极为重视，严令不得外传
- 要求年少之人从头开始修炼
- 修炼者必须具有"灵根"体质——墨大夫不知道什么是"灵根"，但在韩立之前已找过数百名童子都无法修炼
- 修炼到第四层后五感会发生质的提升——视力、听力、嗅觉都变得极其灵敏，身体轻快，精神长足进步
- 第四层才是真正的略有小成
- 练至第四层的人可帮墨大夫运功推拿，用长春气刺激秘穴，使他摆脱困境重新找回精元
- 不同人修炼效果差异极大，墨大夫找不到能修炼的人
- 韩立用黄龙丹和金髓丸突破到第五层，获得过目不忘能力
- 韩立长春功练至第六层（墨大夫口诀的最高一层）
- 第六层长春功恢复抗异常能力远超常人想象——韩立从墨大夫大吼制住后迅速恢复
- 长春功主要在精神、头脑、五感上加强，对身体作用微乎其微
- 长春功能量流（韩立称之为"伪真气"）可在经脉内随意运行，但不能像真气那样威力惊人
- 韩立推测第六层后面还有未完的口诀，后几层可能才是真正的妙用
- 长春功对药力依赖性极大，有灵丹妙药可突破资质限制
- 余子童修炼长春功至第七层，受资质所限无法筑基
- 长春功修为高低决定意识世界中光球体积大小，影响夺舍胜负
- 韩立第六层长春功使其绿球比墨大夫黄球大得多，轻松吞噬墨大夫元神
- 韩立每天把灵药当零食吃，长春功悄悄进入第八层
- 第八层法力深厚程度已超出原来肉身尚存时的余子童
