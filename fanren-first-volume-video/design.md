# Overview

这支视频不是仙侠海报，而是一支带有江湖惊险感的卷一回顾短片。画面应当有旧纸、药笺、山门夜火、冷金字符的质感，核心情绪是“寒、忍、疑、杀、离开”。

# Colors

- 背景保持深墨褐色，不用纯黑。
- 主强调色用旧金色，负责标题、规则线、命运节点。
- 次强调色用药草青，专门服务神秘小瓶、灵药、修仙线索。
- 危险时刻切到暗红色，但只在关键冲突处高亮。

# Typography

- 标题用 `PingFang SC` 粗字，强调利落和现代感。
- 正文用 `Songti SC`，保留一点章回故事感。
- 小标签全部大留白、小字号、紧跟边缘，不做居中卡片排版。

# Components

- 每个场景必须同时有背景纹理、中景标题、前景标签或规则线。
- 允许大面积鬼影文字，比如“墨大夫”“修仙者”“火魔”，但透明度要低。
- 不用圆角卡片和产品 UI 样式，整体更像片头设计而不是网页。

# Do

- 把标题做大，横向占据画面 60% 以上。
- 用分屏、斜切和竖线制造画面张力。
- 让金色与暗红色只在关键动作处爆出来。

# Don't

- 不要蓝紫霓虹。
- 不要渐变字。
- 不要平均分布的卡片栅格。
- 不要把整支片子做成古风海报轮播。
