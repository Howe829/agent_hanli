## 资源文件

`resources/` 目录下存放各卷小说原文，按卷分目录，每章一个 `.txt` 文件。

## 规则与格式

详细的实体页格式、章节页格式、命名规则和 lint 标准见 `fanren-obsidian-vault/AGENTS.md`。

### 实体页必备章节

基本信息、身份/定义、首次登场、当前已知关系、关键事件、相关条目、来源

### 章节页必备章节

章节信息、摘要、登场实体、新增关系、伏笔、来源

### 交叉引用

所有实体引用使用 Obsidian wiki 链接格式 `[[实体名]]`。
