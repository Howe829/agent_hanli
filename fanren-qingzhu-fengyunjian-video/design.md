# Overview

这支片要有“竹、雷、剑阵”三层感受。不是古风挂画，也不是科技 HUD，而是一种冷静、锋利、会进化的兵器系统展示。

# Colors

- 背景用近黑墨绿，不用纯黑。
- 主强调色用竹青，负责飞剑、青莲、体系感。
- 次强调色用雷金，负责金雷竹、辟邪神雷、升级节点。
- 危险红只在“毁剑、困魔、杀局”时闪出。

# Typography

- 所有中文用 `noto sans jp`，保证渲染稳定。
- 小标签和编号用 `ibm plex mono`，增加器物档案感。
- 大标题必须重、宽、短，像剑名砸在屏幕上。

# Components

- 每一幕至少同时有：背景纹理、主标题、数据/标签列。
- 允许大量使用环形剑阵、细剑丝、竹节线条、雷纹爆闪。
- 不做温和卡片栅格，要更像兵器档案与战斗片段的混合体。

# Do

- 强调“十二口 / 三十六口 / 七十二口”的成长递进。
- 用青色与金色对冲表达木雷双属性。
- 让画面有明显斜向切割和旋转张力。

# Don't

- 不要紫蓝赛博风。
- 不要仙侠手游海报味。
- 不要大段居中文案堆砌。
